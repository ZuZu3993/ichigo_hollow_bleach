# АгроСтат KZ

Статический многостраничный сайт для GitHub Pages.

## Запуск
Откройте `index.html` в браузере. Интернет нужен только для Google Fonts и перехода по внешним ссылкам.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий.
2. Загрузите содержимое этой папки **в корень** репозитория.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Дождитесь появления ссылки `https://USERNAME.github.io/REPOSITORY/`.

Все страницы используют относительные ссылки, поэтому работают в подпапке GitHub Pages.

Данные за 2025 год. При сравнении стран учитывайте различие охвата данных. Источники находятся на странице `sources.html` и в подвале.
